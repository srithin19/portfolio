## Local Setup

1. Install [Node.js](https://nodejs.org/) then run:

   ```bash
   npm install
   npm start
   ```

2. Open [http://localhost:3000](http://localhost:3000).

## Deployment (GitHub Pages)

```bash
npm run deploy
```
